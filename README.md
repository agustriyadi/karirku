# Karirku

Python learning project for exploring career development and personal growth.

## Contents

This repository contains small Python exercises and experiments, including:

- Data generation with `random_data.py`
- Memory and profile experiments
- Supporting scripts for local development

## Run locally

From the repository root, run a script with Python 3:

```bash
python random_data.py
```

Other scripts can be run in the same way, depending on the experiment you want to explore.

## Status

This is a personal learning project and may change as new experiments are added.
